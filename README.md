# Train of Thoughts
A collection of smaller projects for demo purpose and knowledge consolidation.

## Repo Structure
This is a mono repo. Each project lives in its own folder named `YYMMDD-project-name-in-kebab-case` and is self-contained, including its own tooling and config. See each project's folder for how to set it up.

Note: `jupytext --to markdown your_notebook.ipynb` to convert to Markdown.
